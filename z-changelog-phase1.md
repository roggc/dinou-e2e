# Changelog — Dinou `10.0.7` (Series Z — Phase 1: Core Production Hardening)

All notable core security, memory-bound, Server Function, DX/HMR, and deployment-adapter fixes uncovered and resolved during Series Z Phase 1 (`z-phase1-tests.md`, Checks `#Z1–#Z5`) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [10.0.7] - Unreleased

### Fixed / Hardened

#### Developer Experience — Live File-Edit HMR Across All 3 Bundlers & Strict `dinou typegen` (`Stage 4 / Check #Z4`)
- **Fixed React 19 RSC `REACT_LAZY_TYPE` state reset after Fast Refresh (`dinou/esbuild/react-refresh/react-refresh-runtime.js`, `dinou/rollup/react-refresh/react-refresh-runtime.js`)**:
  - Wrapped renderer `setRefreshHandler` via `__REACT_DEVTOOLS_GLOBAL_HOOK__` so Fast Refresh's `resolveFamily` unwraps already-resolved `REACT_LAZY_TYPE` client references (`payload.status === "fulfilled" | "resolved_module"`, plus fulfilled `React.lazy` `_status === 1`). Previously, after a client component Fast Refresh patched `current.type` to `v2`, a subsequent Server Component `rsc-update` produced a new `$L` lazy element resolving to the cached `v1` export, failing both `isCompatibleFamilyForHotReloading()` and `resolveLazy(elementType) === current.type`, causing React 19 to unmount the client component and wipe its state.
- **Fixed Rollup dev duplicate-React crash (`Cannot read properties of null (reading 'useState')`) across incremental watch rebuilds (`dinou/rollup/rollup.config.js`)**:
  - Isolated `react`, `react-dom`, and `scheduler` into a stable unhashed `vendor-react.js` chunk (and `commonjsHelpers` into `_commonjsHelpers.js`) via dev `output.manualChunks`, and replaced Rollup's volatile content `[hash]` on remaining dev vendor chunks with a deterministic SHA-1 hash of sorted `moduleIds`. Previously, unrelated watch rebuilds (such as editing a `.module.css` file) changed `index-[hash].js` for `react`, causing hot-reloaded client components to import a second disconnected React instance alongside `main.js`.
- **Fixed strict TypeScript `dinou typegen` custom asset & static route param types (`dinou/core/generate-route-types.js`, `dinou/index.d.ts`)**:
  - Emitted custom wildcard asset declarations (`declare module "*.<ext>"`) into a dedicated ambient script `.dinou/types/assets.d.ts` (zero top-level `import`/`export`) referenced via `/// <reference path="./assets.d.ts" />` from `.dinou/types/routes.d.ts` (pruning `assets.d.ts` when no custom extensions are configured), fixing `TS2307` errors caused by wildcard ambient declarations living inside module-scoped `routes.d.ts`. Also formatted `.env` property keys safely with `formatTsKey()`.
  - Changed static route `params` types from `Record<string, never>` to `Record<never, never>` in `generate-route-types.js` and `index.d.ts` so invalid accesses like `params.nonexistentParam` are properly rejected with `TS2339` under `tsc --noEmit --strict`.
- **Anchored dev-mode internal-output exclusions to `projectRoot` (`dinou/rollup/rollup.config.js`, `dinou/node/dev.js`)**:
  - Anchored Rollup `watch.exclude` regexes (`.git`, `.dinou`, `test-results`, `playwright-report`) to `path.resolve(process.cwd())` and replaced substring `includes("/.dinou/")` / `"/dist/"` / `"/out/"` filters in `dev.js` with project-root-relative `isProjectInternalOutputPath()` so workspaces nested under ancestor directories named `.dinou/`, `dist/`, or `out/` are watched and discovered reliably.

#### Advanced React 19 Server Functions & True Progressive Enhancement (`Stage 3 / Check #Z3`)
- **Added isomorphic rich JS argument serialization & fixed binary Flight stream corruption (`dinou/core/server-function-codec.js`, `dinou/core/server-function-proxy.js`, `dinou/core/server-function-proxy-webpack.js`, `dinou/core/handler.js`)**:
  - Created zero-dependency, edge-safe `server-function-codec.js` (`encodeServerFunctionArgs` / `decodeServerFunctionArgs`) preserving `Date`, `Map`, `Set`, `BigInt`, `Uint8Array` (and all TypedArrays/`ArrayBuffer`/`DataView`), `RegExp`, `URL`, `undefined`, `-0`, `NaN`, `Infinity`, and `-Infinity` across JSON RPC and `multipart/form-data` extra args (including `useActionState` `prevState`), with collision-safe escaping for literal `$dinou_sf` keys, prototype-pollution guards, and full backwards compatibility with legacy plain-JSON `{ id, args }` callers.
  - Replaced the `TextDecoder`/`split("\n")`/`TextEncoder` RSC stream reader in `server-function-proxy.js` and `server-function-proxy-webpack.js` with `createBinarySafeFlightFilterStream()`, fixing silent UTF-8 corruption (`U+FFFD`) and framing breakage whenever a Server Function returns binary `Uint8Array`/`ArrayBuffer` chunks containing non-UTF-8 or `0x0a` bytes while still intercepting Dinou `D:{"type":"redirect"|"cookie"|"revalidate"}` control lines at row boundaries.
- **Eliminated caller `FormData` in-place mutation (`dinou/core/server-function-proxy.js`, `dinou/core/server-function-proxy-webpack.js`)**:
  - Cloned caller `FormData` entries into a fresh `FormData` before attaching `__dinou_func_id`, `__dinou_formData_index`, `__dinou_args`, and `__dinou_args_codec` (and stripped `__dinou_args_codec` on the server in `handler.js`), preventing internal metadata leakage/duplication when callers inspect or re-submit the same `FormData` instance while preserving multi-file binary uploads and UTF-8 filenames byte-for-byte.
- **Implemented true No-JS Progressive Enhancement for React 19 `<form action={serverAction}>` (`dinou/core/handler.js`)**:
  - Added native HTML `<form method="POST">` handling (`multipart/form-data` and `application/x-www-form-urlencoded`) for React 19's `$ACTION_ID_<id>` and `$ACTION_REF_<n>` (bound actions & `useActionState`) hidden inputs on page routes when JavaScript is disabled, enforcing strict production CSRF (`Origin` / `Referer` exact `URL.host` or `allowedOrigins` + `Sec-Fetch-Site: cross-site` block), streaming `413` body-size caps, manifest allowlist + `src/` realpath containment, stripping all `$ACTION_*`/`__dinou_*` internal fields, and returning `303 See Other` PRG / redirect responses carrying all `Set-Cookie` headers.
- **Normalized default `Path=/` on `res.clearCookie()` & streaming `D:{"type":"cookie"}` mutations (`dinou/core/handler.js`)**:
  - Defaulted `Path=/` in `WebResponseBridge.clearCookie()` and in post-headersSent `createServerFunctionContext.res.cookie()` / `clearCookie()` (also preserving `domain`, `secure`, `sameSite` attributes) so concurrent Server Functions mutating and clearing cookies remain consistently visible across immediate `router.refresh()` and `refreshSlot()`.

#### Long-Running Server & Client Memory Bounds — Deterministic LRU & TTL Eviction (`Stage 1 / Check #Z1`)
- **Bounded server-side slot caches & active TTL sweep (`dinou/core/cache-slot.js`)**:
  - Enforced a deterministic LRU cap on `slotRegistry` (`MAX_SLOT_REGISTRY_ENTRIES = 1000`, configurable via `DINOU_MAX_SLOT_REGISTRY_ENTRIES`) via `setBoundedSlotRegistry()` / `touchSlotRegistry()`, and bounded per-slot `slotRouteKeys` sets (`MAX_SLOT_ROUTE_KEYS_PER_SLOT = 100`) so parameterized dynamic slots (`<DinouCacheSlot id={`product-${params.id}`}>`) never retain closures or route sets indefinitely while transparently re-discovering evicted slots on demand.
  - Added O(1)-amortized TTL expiration sweep (`RECENT_FRESH_SLOT_TTL_MS = 500`) + LRU cap (`MAX_RECENT_FRESH_SLOTS = 256`, configurable via `DINOU_MAX_RECENT_FRESH_SLOTS`) in `setRecentFreshSlotRender()` so one-off dynamic fresh-slot JSX trees are evicted promptly instead of staying in RAM forever.
  - Enforced an LRU cap on `slotRenderGenerations` (`MAX_SLOT_GENERATIONS = 2000`, configurable via `DINOU_MAX_SLOT_GENERATIONS`) in `bumpSlotRenderGeneration()`, skipping keys with active `inflightSlotRenders`.
- **Eliminated 404 scanner-bot memory amplification & bounded per-route handler/layout/build caches (`dinou/core/handler.js`, `dinou/core/layout-functions.js`, `dinou/core/asset-extensions.js`, `dinou/core/server-css-modules-plugin.js`)**:
  - Stopped inserting nonexistent 404 routes (`!pagePath`) into global `isDynamic` (`Symbol.for("dinou.isDynamic.map")`), returning an ephemeral `{ value: false }` object instead so 404 scanner storms add zero Map entries; enforced an LRU cap on `isDynamic` (`MAX_IS_DYNAMIC_ENTRIES = 1000`, configurable via `DINOU_MAX_IS_DYNAMIC_ENTRIES`) and `pageFunctionsConfigCache` (`MAX_PAGE_FUNCTIONS_CONFIG_ENTRIES = 500`).
  - Enforced a `500`-entry LRU cap on `layoutFunctionsPathCache` and `layoutFunctionsConfigCache` in `layout-functions.js` (alongside the existing `1000`-entry `activeLayoutChainCache`).
  - Enforced LRU caps on `assetHashCache` (`2000`) and `syncConfigExtCache` (`64`) in `asset-extensions.js`, and on `serverCssModuleCache` & `lastKnownExportJsonByFile` (`DEFAULT_MAX_CSS_MODULE_CACHE_ENTRIES = 1000`, configurable via `DINOU_MAX_CSS_MODULE_CACHE_ENTRIES`) in `server-css-modules-plugin.js`.
- **Bounded client-side SPA router & slot caches without evicting mounted/active trees (`dinou/core/slot.js`, `dinou/core/client.jsx`, `dinou/core/client-webpack.jsx`)**:
  - Added unmounted-only LRU eviction (`evictUnmountedClientSlots()`, default cap `50`, configurable via `window.__DINOU_MAX_CLIENT_SLOT_CACHE_ENTRIES__` / `window.__DINOU_MAX_CLIENT_CACHE_ENTRIES__`) on `knownClientSlots` and `slotOverrideCache` in `slot.js`, releasing `baseChildren`, `baseChildrenSet`, and `content` React subtree references on eviction while never evicting currently mounted subscribers or in-flight `pendingPromise` entries.
  - Enforced LRU caps on `pageCache` (`50`), `layoutCache` (`50`), and `scrollCache` (`100`) across both `client.jsx` and `client-webpack.jsx` (configurable via `window.__DINOU_MAX_CLIENT_CACHE_ENTRIES__`), skipping the currently active route/layout, cleaning up auxiliary `errored*`/`volatile*` sets on eviction, and exposing `window.__DINOU_PAGE_CACHE__`, `window.__DINOU_LAYOUT_CACHE__`, and `window.__DINOU_SCROLL_CACHE__` for soak observability.

#### HTTP Security & Hardening — CSRF Origin/Host Validation, Body Size DoS Caps, Production Error Sanitization, Open Redirect Prevention & Path/Symlink Confinement (`Stage 2 / Check #Z2`)
- **Fixed Server Function CSRF bypasses, untrusted `X-Forwarded-Host` spoofing, missing `Sec-Fetch-Site` check, and unbounded JSON/multipart body-size DoS risk (`dinou/core/handler.js`)**:
  - Replaced the vulnerable `origin.includes(host)` substring check on `POST /____server_function____` with strict `new URL(origin)` parsing verifying `http:`/`https:` scheme and exact case-insensitive `originUrl.host === expectedHost` equality (closing `https://localhost:3000.evil.com` and `https://evil.com/localhost:3000` bypasses).
  - Stopped blindly trusting `X-Forwarded-Host` by default (preventing external `X-Forwarded-Host: evil.com` + `Origin: https://evil.com` CSRF spoofing); `X-Forwarded-Host` is now honored only when explicitly opted in via `dinou.config` (`security.trustProxy: true` / `trustProxy: true`) or `DINOU_TRUST_PROXY=true`, alongside optional `security.allowedOrigins` / `allowedOrigins` allowlisting.
  - Added production `Sec-Fetch-Site: cross-site` blocking (`403 Forbidden`) unless the `Origin` is explicitly allowlisted.
  - Added streaming `readRequestBodyWithLimit()` enforcing configurable body-size limits (`security.maxServerFunctionBodyBytes` / `maxServerFunctionBodyBytes` / `DINOU_MAX_SERVER_FUNCTION_BODY_BYTES`; safe defaults: `1 MB` JSON, `10 MB` multipart, `64 KB` on `POST /____rsc_payload_error____`) across both declared `Content-Length` headers and chunked streams without `Content-Length`, returning `413 Payload Too Large` without OOM or Undici stream-cancel crashes, and exported `DinouSecurityConfig` on `DinouConfig` in `dinou/index.d.ts`.
- **Fixed production error message & dev-title leakage across Server Functions, `error.tsx`, `@slot/error.tsx`, isolated layout errors, `<DinouCacheSlot>` discovery, emergency HTML fallbacks, and client ErrorBoundary (`dinou/core/handler.js`, `dinou/core/get-error-jsx.js`, `dinou/core/get-jsx.js`, `dinou/core/layout-composition.js`, `dinou/core/cache-slot.js`, `dinou/core/client.jsx`, `dinou/core/client-webpack.jsx`)**:
  - Redacted uncaught Server Function errors in `NODE_ENV=production` to `{ error: "Internal Server Error" }` while continuing to preserve intentional developer errors that attach `err.digest` (or `err.expose === true`).
  - Fixed production error leakage in `get-error-jsx.js` (default fallback, `!error.stack` branch, and `@slot/error.tsx`), `get-jsx.js` (`@slot/error.tsx` and isolated layout error catches), `layout-composition.js` (`renderSingleLayoutLevel` and `SafeParallelSlot` error catches), and `cache-slot.js` (`error.tsx` cold slot discovery).
  - Propagated intentional `err.digest` consistently across SSR, RSC, `POST /____rsc_payload_error____`, `window.__DINOU_ERROR_DIGEST__` bootstrap script, and `client.jsx` / `client-webpack.jsx` hydration (fixing a real `#418` hydration mismatch where `error.digest` rendered on SSR was dropped after client hydration).
  - Replaced hardcoded `<title>Dinou Dev Error</title>` in `handler.js` emergency fallback HTML and `<title>"Dinou Dev Error from client.jsx ErrorBoundary"</title>` in `client.jsx` / `client-webpack.jsx` with `${isDevelopment ? "Dinou Dev Error" : "Application Error"}`.
- **Fixed Open Redirect & XSS-via-Redirect gaps across Server & Client layers (`dinou/core/handler.js`, `dinou/core/server-function-proxy.js`, `dinou/core/server-function-proxy-webpack.js`, `dinou/core/client-redirect.jsx`, `dinou/core/client.jsx`, `dinou/core/client-webpack.jsx`, `dinou/core/ppr-runtime.js`, `dinou/core/navigation-utils.js`)**:
  - Added strict `isSafeRelativeRedirectPath()` / `isSafeExternalHttpUrl()` / `sanitizeRedirectUrl()` validation blocking protocol-relative (`//evil.com`, `///evil.com`), backslash-prefixed (`/\evil.com`, `\/evil.com`), dangerous URI schemes (`javascript:`, `data:`, `vbscript:`), and ASCII control characters (`\r`, `\n`, `\t`, `\0` — preventing CRLF header injection), clamping unsafe redirect targets to `"/"` while preserving legitimate internal routes (`/dashboard?tab=1#top`) and deliberate `http://`/`https://` external navigations (`router.push`, `router.replace`, `<ClientRedirect>`, SSR `res.redirect`).
  - Enforced relative-only redirects in Server Functions (`createServerFunctionContext.res.redirect`, `server-function-proxy.js`, and `server-function-proxy-webpack.js`).
  - Updated `isExternalUrl()` in `navigation-utils.js` to recognize backslash-prefixed paths (`/\`, `\/`) so they are never treated as safe relative routes.
- **Hardened Path Traversal, Real Symlink Escape Confinement & Server Function ID Validation (`dinou/core/static-assets.js`, `dinou/core/storage-adapter.js`, `dinou/core/handler.js`, `dinou/cloudflare/shims/fs.js`)**:
  - Added `fs.realpathSync()` symlink-escape containment inside `resolveConfinedStaticFile()` (with case-insensitive Windows prefix comparison and Cloudflare `shims/fs.js` `realpathSync` parity) and double-encoded traversal rejection (`%252e%252e`, `%255c`, `%2500`, double-encoded dotfiles) in `normalizePublicRequestPath()` and `decodePathSegmentsSafely()`.
  - Added zero-syscall lexical path-confinement (`..`, `\`, `\0`, baseDir prefix guard) in `FileSystemStorage._resolve()`, returning `null`/`false` on `get`/`has`/`getSlotMetadata` and refusing unsafe `set`/`delete` outside `baseDir` while preserving `OPT-4`'s zero-`existsSync` hot path.
  - Hardened `GET /____rsc_slot____/*` against multi-segment traversal (`/____rsc_slot____/slot/extra`), double-encoded slot IDs, and traversal in `x-dinou-current-path` (`400 Bad Request`), and added `decodePathSegmentsSafely()` confinement to `POST /____rsc_payload_error____/*`.
  - Hardened `POST /____server_function____` `id` parsing against null bytes, prototype/empty export names (`__proto__`, `constructor`, `prototype`), percent-encoded traversal (`file:///src/%2e%2e/...`), and `src/` realpath containment.
