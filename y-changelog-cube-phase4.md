# Changelog — Dinou `10.0.4` (Phase 4 — Orthogonal 3D Caching Cube Hardening)

All notable core bug fixes uncovered and resolved during Phase 4 (`y-phase4-cube-tests.md`, Checks `#67–#72`) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [10.0.4] - Unreleased

### Fixed

#### Sibling Route Groups `(groupA)` / `(groupB)` & Optional Catch-All (`[[...slug]]` / `[[param]]`) Layouts
- **Eliminated storage, SSG, client-router, and revalidation collisions across sibling Route Group layouts and 0-segment optional dynamic layouts** (`dinou/core/layout-functions.js`, `dinou/core/get-file-path-and-dynamic-params.js`, `dinou/core/discover-layouts.js`, `dinou/core/client.jsx`, `dinou/core/client-webpack.jsx`, `dinou/core/build-static-pages.js`, `dinou/core/handler.js`, `dinou/core/get-jsx.js`, `dinou/core/cache-revalidate.js`, `dinou/core/cache-slot.js`):
  - `getActiveLayoutChain()` (`layout-functions.js`) and `buildStaticPages()` (`build-static-pages.js`) previously stripped `(group)` segments and collapsed empty `[[...slug]]` / `[[param]]` segments when deriving `cleanLayoutKey` and `layoutRoutePath`. As a result, sibling route-group layouts (e.g., `(alpha)/layout.tsx` and `(beta)/layout.tsx` under a shared prefix) and a 0-segment optional catch-all layout (`[[...slug]]/layout.tsx` under a parent `layout.tsx`) computed identical storage keys and overwrote each other's `shell.layout.own.json`, `shell.layout.json`, `layout.rsc`, and `layout.metadata.json`.
  - Added `computeLayoutKeyFromFolder()` in `layout-functions.js` (reused by `build-static-pages.js`) to preserve `(group)` segments and empty optional markers (`[[...slug]]` / `[[param]]`) in `cleanLayoutKey` and `layoutRoutePath`, and registered all active static layouts from `getActiveLayoutChain()` for every discovered static/PPR page in `build-static-pages.js` (skipping unresolved `dynamicStructure.length > 0` templates) so 0-segment optional catch-all layouts and dynamic-group layouts are never omitted from SSG.
  - Added `getLayoutsForLayoutKey()` in `get-file-path-and-dynamic-params.js` and wired `exactLayoutKey: true` across internal `/____rsc_layout____` (`handler.js`, with segment `decodeURIComponent` decoding for browsers such as WebKit that percent-encode `[` / `]`), `getJSX(..., { segment: "layout" })` (`get-jsx.js`), and `revalidateLayout()` (`cache-revalidate.js`) so internal layout endpoints target the exact group or optional catch-all layout without leaking sibling groups, while keeping public URLs containing literal `(group)` segments strictly returning `404`.
  - Updated `discoverLayoutsFromFileRelPaths()` (`discover-layouts.js`) to emit template-preserving specs (`~<layoutFolderRel>`) whenever a page's nearest layout folder contains `(group)` or `[[...]]` segments, and updated `matchRoutePattern()` + `getLayoutKey()` in both `client.jsx` and `client-webpack.jsx` to expand captured URL segments into the canonical layout key — preserving client state on same-group soft `<Link>` navigation while swapping sibling route-group layouts cleanly on cross-group navigation.
  - Updated `getSlotJSX()` host-layout persistence in `cache-slot.js` to resolve candidate host layout keys via `getActiveLayoutChain()` instead of naive URL-prefix splitting, ensuring live `refreshSlot()` on `<DinouCacheSlot>`s inside `(group)` or `[[...slug]]` layouts persists into the exact host `shell.layout.own.json` and `layout.rsc`.

#### Distributed Storage (`DenoKVStorage` Multi-Isolate Edge Consistency & Chunked Payloads)
- **Added cross-isolate tombstones, distributed tag invalidation timestamps, atomic orphaned-chunk cleanup, and incomplete-chunk read protection to `DenoKVStorage`** (`dinou/core/storage-adapter.js`):
  - `DenoKVStorage` previously inherited isolate-RAM-only `isKeyDeleted()`, `markTagInvalidated()`, `markTagInvalidatedAsync()`, and `getTagInvalidatedAtAsync()` from `StorageAdapter`, allowing a cold Deno Deploy isolate (`Isolate B`) to miss deletions or `revalidateTag` invalidations performed by `Isolate A` and resurrect stale `.dinou/dist2` pages or `<DinouCacheSlot>`s via `readDist2Fallback()` / `getSlotJSX()`. Added distributed KV tombstones (`["dinou_cache_tombstone", cleanKey]`) and tag invalidation keys (`["dinou_cache_tag_inv", tag]`) synced across `delete()`, `set()`, `isKeyDeleted()`, `markTagInvalidated()`, `markTagInvalidatedAsync()`, and `getTagInvalidatedAtAsync()`, while keeping internal namespaces completely invisible to `keys()`.
  - Fixed orphaned chunk leaks when overwriting a chunked (`>16 KiB`) entry with a smaller (`<16 KiB`) or shorter chunked payload: `set()` now inspects any existing `totalChunks` and atomically removes stale excess `["dinou_cache_chunk", targetKey, i]` entries alongside writing the new payload and clearing tombstones for both the key and its companions (`index.html` ↔ folder key, `slot.json` ↔ `slot.metadata.json`).
  - Hardened `get()` against partial/corrupt chunk reads by returning `null` if any chunk `0..totalChunks-1` is missing instead of returning truncated HTML/JSON, updated `delete()` to atomically purge chunks + headers + write tombstones across the key and all companion keys, normalized `keys(prefix)` matching, and added optional `options.hydrateFromDisk` constructor support matching `RedisStorage`.

#### Server Functions (`"use server"`, Bound Closures & `<DinouCacheSlot>` / PPR Deserialization)
- **Fixed `#null` `$$id` corruption when deserializing cached Server Function references under `@roggc/react-server-dom-esm`** (`dinou/core/cache-slot.js`):
  - `deserializeJSX()` previously passed the already-qualified `value.id` (e.g., `"file:///src/sf/actions.ts#ping"`) alongside `exportName = null` to `registerServerReference(serverRef, value.id, null)`. While `react-server-dom-webpack` treats `exportName === null` as a no-op, `@roggc/react-server-dom-esm` unconditionally concatenates `id + "#" + exportName`, corrupting every deserialized Server Function reference (both imported and `.bind()`ed inline `"use server"` closures) to `"file:///src/sf/actions.ts#ping#null"`.
  - Split `value.id` at `lastIndexOf("#")` into `(moduleId, exportName)` before invoking `registerServerReference()`, ensuring 100% identical `$$id` and `$$bound` preservation across both `react-server-dom-webpack` and `@roggc/react-server-dom-esm` on `slots/*/slot.json`, `shell.layout.own.json`, and `shell.page.json` round-trips.

#### Custom Middleware & Plugin Context Propagation (`copyCustomContextProperties` & Multi-Tenant Cache Isolation)
- **Propagated custom middleware/plugin context into live `<DinouCacheSlot>` discovery and eliminated cross-tenant leaks on `revalidate = 0` slots and shared static shell rebuilds** (`dinou/core/request-context.js`, `dinou/core/cache-slot.js`, `dinou/core/handler.js`):
  - Centralized and exported `copyCustomContextProperties(source, target)` in `request-context.js` (removing the private copy in `handler.js`) and expanded its reserved internal-key exclusion list (`_isSlotDiscovery`, `_slotTags`, `_layoutSlotTags`, `_pageSlotTags`, `_resolvedPageClientJsx`, `_resolvedLayoutClientJsx`, `_hasResolvedSegments`, `_redirectLocation`, `_dinouUseIdCount`) so internal engine state is never accidentally copied onto sibling contexts.
  - Updated `createDiscoveryContext()` (`cache-slot.js`) to invoke `copyCustomContextProperties(outerCtx, discoveryCtx)` whenever `outerCtx && !outerCtx._isStaticHtmlRender`, ensuring cold-server `/____rsc_slot____/<id>` slot discovery preserves custom plugin/middleware properties (`ctx.*` and `ctx.req.*`) on dynamic layout/page hosts while keeping static revalidation discovery completely clean.
  - Fixed a **critical cross-tenant leak** in `getSlotJSX()` (`cache-slot.js`): `isEntryNoCache` (`entry.revalidate < 1`) was previously evaluated *after* `inflightSlotRenders` and the 500ms `recentFreshSlotRenders` stampede cache (both keyed solely by `storageKey + queryKey`), causing concurrent or `<500ms` sequential `/____rsc_slot____/<id>?fresh=1` calls against a `revalidate = 0` dynamic slot to return Tenant A's private data to Tenant B. Moved `isEntryNoCache` ahead of both maps and bypassed `inflightSlotRenders` and `recentFreshSlotRenders` whenever `isEntryNoCache` is true.
  - Fixed a **cross-tenant static-shell poisoning leak** in `handler.js`: removed `copyCustomContextProperties(rootContext, ...)` and stripped user `headers` from `recomposeCtx` (cached HTML recomposition) and `staticPageCtx` (cold-ISG `shell.page.json` / `page.rsc` rebuild underneath a dynamic layout), ensuring a live request's plugin/middleware tenant properties or headers can never be baked into shared disk/KV static shell artifacts.

#### Client Router Query Transitions, Layout Prefetching & `router.refresh()` Cache Coherence
- **Fixed query-parameter layout prefetching, `pageCache` query-variant eviction on `router.refresh()`, and `useSearchParams()` transition coherence** (`dinou/core/client.jsx`, `dinou/core/client-webpack.jsx`, `dinou/core/navigation.js`):
  - `window.__DINOU_PREFETCH__` (`client.jsx`, `client-webpack.jsx`) previously stripped query strings before checking `layoutCache` and calling `getLayoutPayload(lKey)`, causing hovering a `<Link href="/route?tab=metrics">` on a PPR route to issue a wasted queryless `/____rsc_layout____/route` fetch (polluting `layoutCache`) instead of prefetching `${lKey}${searchPart}`. Extracted `prefetchSearchPart` from `cleanUrl` and passed it to both the `layoutCache` lookup and `getLayoutPayload(lKey, prefetchSearchPart)`.
  - `router.refresh()` (`client.jsx`, `client-webpack.jsx`) previously evicted all query-string variants of `currentLayoutKey` from `layoutCache` (when `{ layout: true }`), but only deleted the exact `currentPath` from `pageCache` — leaving sibling query entries (e.g., `?tab=metrics&sort=desc`) stale in `pageCache` and desynchronized from freshly-fetched layouts when pressing browser `Forward`/`Back`. Updated `refresh()` to clear `window.__DINOU_ACTIVE_LAYOUT__` and evict all same-pathname query keys (`k === currentPathname || k.startsWith(currentPathname + "?")`) from `pageCache`.
  - Fixed `useSearchParams()` (`navigation.js`) during pending `startTransition` navigations from a queryless URL (`/route`) to a parameterized URL (`/route?tab=metrics`): previously, when `RouterContext.url` had no `"?"`, `useSearchParams()` fell through to `window.location.search` (already updated synchronously by `history.pushState`), prematurely leaking target query params into the outgoing route's pending render. When `RouterContext.url` is a non-empty string, `useSearchParams()` now treats it as authoritative and returns an empty `URLSearchParams()` if it contains no `"?"`.

#### Staggered PPR Streaming Abort Safety, Node HTTP Disconnect Cleanup & `$RB` Orphan Pruning
- **Eliminated unhandled rejections, false PPR hole error logs, and detached `$RB` DOM leaks during mid-stream client aborts** (`dinou/core/ppr-runtime.js`, `dinou/core/http-adapter.js`, `dinou/core/slot.js`):
  - In `handlePprResume()` and `streamDynamicHoles()` (`ppr-runtime.js`), `writer.write()` was previously invoked inside each hole's `try { ... } catch (holeErr)` block without tracking `writer.closed` cancellation: when a browser or edge client aborted a streaming PPR response mid-flight while slower holes were still pending, `writer.write()` threw `TypeError`, entered `catch (holeErr)`, logged a false `[Dinou PPR] Error resolving dynamic hole`, rendered a fake error element, threw again on the second `writer.write()`, and turned still-running sibling holes in `Promise.all(holePromises)` into unhandled promise rejections. Added an abort-aware `safeWrite` / `isAborted` controller backed by `writer.closed.catch(...)`, decoupled hole rendering from `safeWrite`, switched to `Promise.allSettled(holePromises)`, skipped post-abort inline RSC / postlude work, and safely released the writer lock in `finally`.
  - Updated `sendWebResponseToNode()` (`http-adapter.js`) to listen for premature Node `res` `"close"` events (before `res.writableEnded`) and destroy the `Readable.fromWeb(webResponse.body)` stream immediately (propagating `.cancel()` to `handlePprResume` on HTTP/1.1 keep-alive disconnects) while suppressing benign client-abort error logs (`ERR_STREAM_PREMATURE_CLOSE`, `ECONNRESET`, `AbortError`).
  - Updated `pruneOrphanedSsrStreams()` (`slot.js`) to treat `boundaryTpl.isConnected === false` as detached alongside `!boundaryTpl.parentNode`: previously, React unmounting an ancestor container left nested `<template id="B:n">` nodes with a non-null detached `parentNode`, preventing `window.$RB` from pruning those orphaned boundaries after mid-stream navigations.
